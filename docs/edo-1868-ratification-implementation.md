# 1868：約定保持と新政府審査の修正・検証報告

更新日：2026-09-25。ローカル検証と本番反映・配信確認を完了。

## 修正内容とデータフロー

既存Canonical Ledgerのproposalsへ詳細clausesを追加した。条項ID、版、原発言、対象、義務主体、範囲、期間、財源、承認権限、依存先、受諾と履行状態を保持する。別の状態管理は追加していない。包括署名は既存提案IDを参照し、詳細を短い要約で上書きしない。

軍艦の指揮・保管・監督・使用制限・移管を別の意味属性として保存し、暫定管理と移管後を区別する。改訂は旧条項IDを一つずつ指定し、変更していない約束は原発言とともに継承する。一条項を分割する場合も、別の分割先で変更した旧条件を復活させない。通常の任用条件の変更は、軍艦用の時期区分の違いだけで旧保証を残さない。

勝との合意と新政府の承認を分離した。政府は確定条項のスナップショットを版付きのゲーム内政策で審査する。最新の総合点や決着時の自由文要約は承認の根拠にしない。所領、財源、任用枠、軍事管理、引継ぎ、累積負担を審査し、根拠と対象条項IDを保存する。個人保証だけで失敗にはせず、裏付けがあれば追認できる。旧版への承認を変更後に流用できない。

自由文 → requestKatsuResponse（1ターン1回）→ 構造化更新 → compileUpdates → 原発言参照の解決 → reduceNegotiationEvents → Canonical Ledger。

プレイヤーの決着要求 → evaluateSettlement → 勝のACCEPTED / NOT_READY / BREAKDOWN → ACCEPTEDの場合のみsubmitGovernmentReview → 条項別findings / clauseReviews → 承認なら結末、修正要求なら再交渉または空手形として終了。

修正要求を受けたプレイヤーは勝との会談へ戻れる。変更しない合意は維持する。結末は約定と政府の判断理由を描写し、将来の義務を履行済みとは書かない。政府の回答は振り返り画面にも残る。

## 実API検証の結果

モデルはgemini-3.1-flash-lite。プレイヤーへ渡すゲーム情報は使命、獲得ノート、会話、画面のボタンのみ。内部台帳、スコア、未解決論点一覧は渡さない。モデルがCONTINUE / REQUEST_SETTLEMENT / ABORTを選び、24会話ターン・決着要求3回を安全上限とする。

全シナリオを一回の同一試行で通過したという意味ではない。A・E・Fは改訂対応の修正後、B・C・D・Hは最後の任用分類の指示修正後に再試験した結果である。失敗したC・Hは原因分析後の対象再試験で通過。最後の `EDO_SCENARIOS=H,B,C,D npm.cmd run test:edo:live` は終了コード0。試行ごとのsourceDigest、全会話、各ターンの台帳、判定をtest-resultsに保存し、旧版の成功へ差し替えていない。

Dの最新試行は自律的に6ターンで終了した。初回の家名・減封条項は同じIDと内容で最後まで残り、2ターン目に成立した半年の生活支援も最終スナップショットに残った。より長い保持は以前の10ターン実API試行と、15回の包括確認を重ねる決定的テストで補完した。最終候補で24ターンを完走したわけではない。

## 途中で見つけた問題と対処

包括確認による詳細の再生成、無関係な否定文による合意取り消し、関連議題タグの欠落、軍艦改訂での他条件消失、任用の時期区分による旧保証残存、同じ議題の扶持と任用の混入を修正し、回帰テストへ追加した。

テスト役の所領維持指示がB以外へ混入した例、Bの目標8で対象が省略された例、翌朝を待ち続ける例、強硬路線から救済へ転向した例もあり、ゲームの不具合と区別してテスターを修正した。失敗・停止・不正JSONを成功へ置換していない。詳細意味定義と一般指示の「能力による限定は選抜」という矛盾を除き、全員を雇って能力で職種を割り振る場合と採否の選抜を区別した。

## 自己検証と残る制約

要求充足8/10、正確性9/10、検証8/10、簡潔さ8/10、形式9/10、安全性9/10。

1. 結末が期待どおりでも細部を落としていないか：Bの10項目を原発言・条文・意味属性・政府根拠まで照合した。
2. 改訂で古い保証を復活・混入させないか：旧条項の明示参照と継承ルールを修正し、同一議題・条項分割・時期区分を回帰テストに追加した。
3. 確率的出力を常に正しいと扱っていないか：失敗履歴と試行の版を保持した。政府審査は同一スナップショットなら決定的だが、自然言語からの抽出はLLMに依存し、未検証の言い回しで誤分類・不足が生じる余地は残る。

政府の制約は歴史ゲーム用の政策であり、実際の新政府の財政能力を定量再現するものではない。個別の誤抽出を全て防げる保証はない。問題が再現した場合は、該当ターンの原発言・イベント・確定条項を照合できる形で改善する。
